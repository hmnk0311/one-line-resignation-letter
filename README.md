A one-line resignation letter in the voice of a rate limit: it
rejected 40,000 requests today, let the other 100 a minute
through, and the postmortem still lists it as the outage. The
program writes that line, word for word, to
`/output/entry.txt` (126 characters, one line).

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
